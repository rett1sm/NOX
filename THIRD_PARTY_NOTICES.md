# Third-party notices

## Respring component

`Nox/Services/RespringRunner.swift` adapts the WebKit-based SpringBoard refresh technique used by [Erosion](https://github.com/jailbreakdotparty/Erosion), specifically its `Erosion/Helpers/App/Respring.swift` implementation. Erosion is licensed under GNU GPL version 3; the applicable license text is included in [LICENSE](LICENSE).

Credits stated by the upstream implementation:
- @neonmodder123 — original WebKit respring approach.
- @skadz108 — Swift implementation.

This repository does not include Erosion's `worse_query` exploit or its system file-access backend. The NOX wallpaper and passcode screens currently provide local library/preview functionality only, as described in the README.

Other projects used as feature references, not copied source code:
- [Pocket Poster](https://github.com/leminlimez/Pocket-Poster) — PosterBoard wallpaper workflow.
- [AirCard-iOS](https://github.com/Mak5er/AirCard-iOS) — passcode dialer theme concepts.
